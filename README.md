# Latihan Navigasi (latihalogi.io)

Simple navigation landing page practice project.

## Quick Start
Open `index.html` in any web browser to view the site.

## Features
- Navigation bar with Home, About, Contact sections.
- Profile image.
- Responsive design (basic).

## Files
- `index.html`: Main HTML structure with sections.
- `style.css`: CSS styling for nav and layout.
- `assetp/images/Profil.png`: Profile picture.

## Tech Stack
- HTML5
- CSS3

Live at: https://latihalogi.io (deploy as needed).
